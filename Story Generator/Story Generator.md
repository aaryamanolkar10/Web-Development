# 🎲 Random Story Maker

A fun JavaScript project that generates random and humorous stories every time the user clicks a button. The application combines random words and phrases to create unique stories, making each generation different from the last.

## 🚀 Features

* Generates a brand-new random story with every click.
* Uses JavaScript arrays and random selection.
* Interactive button to create unlimited stories.
* Responsive and modern user interface.
* Beginner-friendly project demonstrating core JavaScript concepts.

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)

## 📚 Concepts Practiced

* Variables and Constants
* Arrays
* Functions
* Random Number Generation (`Math.random()`)
* DOM Manipulation
* Event Handling
* Template Literals
* Responsive Web Design

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Double-click `index.html` or open it in any modern web browser.
4. Click the **Generate Story** button to create a new random story.
