# 🧠 Trivia Bot Quiz

A simple interactive Trivia Quiz web application built using **HTML, CSS, and JavaScript**. The project presents multiple-choice questions, provides instant feedback, keeps track of the user's score, and allows the quiz to be restarted after completion.

---

## 🚀 Features

- Multiple-choice trivia questions
- Instant answer validation
- Highlights correct and incorrect answers
- Score tracking
- Next question navigation
- Restart quiz functionality
- Responsive and clean user interface
- Built using vanilla JavaScript (no frameworks)

---

## ▶️ How to Run

1. Clone the repository.

```bash
git clone https://github.com/your-username/TriviaBot.git
```

2. Navigate to the project folder.

```bash
cd TriviaBot
```

3. Open `index.html` in any modern web browser.

**OR**

Open the project in **Visual Studio Code** and run it using the **Live Server** extension.

---

## 🎮 How to Play

1. Read the displayed question.
2. Select one of the available answers.
3. The application immediately indicates whether your answer is correct.
4. Click **Next** to continue.
5. After answering all questions, your final score is displayed.
6. Click **Play Again** to restart the quiz.
