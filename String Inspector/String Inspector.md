# 🔍 Build a String Inspector

A simple JavaScript mini project built as part of the **freeCodeCamp JavaScript course**. This project demonstrates how to use the `includes()` and `slice()` string methods to inspect and manipulate text.

## 📌 Features

* Check whether a string contains a specific word using `includes()`
* Demonstrate case-sensitive string searching
* Extract parts of a string using `slice()`
* Display results in both the browser and the developer console
* Clean and beginner-friendly code structure

## 🛠️ Technologies Used

* HTML5
* JavaScript (ES6)

## 🚀 Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/your-username/build-a-string-inspector.git
   ```

2. Open the project folder.

3. Launch `index.html` in your preferred web browser.
