# 📚 JavaScript Teacher Bot

A beginner-friendly JavaScript project that demonstrates fundamental string operations through a simple Teacher Bot.

## 🚀 Features

- 👋 Prints greeting messages
- 📝 Uses template literals
- 📏 Finds string length
- 🔤 Accesses characters using indexing
- 🔍 Searches substrings with `indexOf()`
- 💻 Displays output in both the browser and the console

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 📂 Project Structure

```
TeacherBot/
│── index.html
│── README.md
```

## ▶️ How to Run

1. Clone this repository.
2. Open the project folder.
3. Double-click **index.html** or open it in any modern web browser.
4. Open the browser's Developer Tools (`F12`) and navigate to the **Console** to view the console output.

## 📖 Concepts Covered

- Variables (`const`)

- Character Indexing

The application displays:

- Greeting messages

The same output is visible on the webpage and in the browser console.
