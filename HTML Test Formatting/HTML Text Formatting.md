# Personal Details Web Page

## Aim
Create a simple HTML page displaying personal details using text formatting tags.

---

## HTML Code

```html
<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <title>Personal Details</title>
</head>

<body>

    <h1><u>Personal Details</u></h1>

    <p><b>Name :</b> Arya Rokade</p>

    <p><i>Course :</i> Computer Engineering</p>

    <p><strong>College :</strong> XYZ College</p>

    <p><em>City :</em> Pune</p>

    <p><mark>Hobby :</mark> Playing Cricket</p>

    <p>Email : arya@gmail.com</p>

    <p>H<sub>2</sub>O is water</p>

    <p>x<sup>2</sup> + y<sup>2</sup></p>

</body>
</html>
```

---

## Output
The webpage displays personal details using different HTML text formatting tags like:
- Bold
- Italic
- Underline
- Strong
- Emphasized
- Highlighted text
- Subscript
- Superscript

---

## Conclusion
A simple HTML webpage was created successfully using various text formatting tags.
